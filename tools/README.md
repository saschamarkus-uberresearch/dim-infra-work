## Adding a New Tool

When adding a new tool to this directory:

1. Create a subdirectory with a descriptive name (e.g., `database-migrator/`)
2. Include a README.md with:
   - Purpose and description
   - Installation/setup instructions
   - Usage examples
   - Dependencies
   - Any configuration requirements
3. Add an entry to this README listing the new tool

## Tool Organization

Tools should be organized by:
- Creating a subdirectory for each tool
- Including all necessary files and documentation
- Ensuring the tool is self-contained when possible
